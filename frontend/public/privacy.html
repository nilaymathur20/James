Privacy Policy

Last updated: October 2, 2026

James is a local-first personal AI assistant. Your data stays on your machine. This policy explains what data James handles, where it goes, and the few cases where optional cloud services are used only when you explicitly enable them.

1. Local Data Storage

James stores all persistent data locally on your device:

  • RAG index — a SQLite FTS5 database (data/rag_index.db) containing indexed text chunks from files and web pages you choose to index.
  • File catalog — metadata (name, path, size, timestamps) for indexed and discoverable files. File contents are never stored in the catalog.
  • Edit proposals & backups — pending edit proposals and backup copies of files before edits are applied. Backups are stored in backups/ with owner-only permissions.
  • Chat history — if you opt in per-request (use_history: true) and the feature is not disabled globally, conversation prompts and responses are saved as Markdown files in history/.
  • Audit log — content-free records of file operations (preview, open, edit proposed/applied/undone) stored in the same SQLite database.
  • Trusted devices — device pairing metadata for P2P features, stored in the same SQLite database.

All local files are created with 0600 permissions (owner read/write only) and directories with 0700.

2. Cloud Services (Opt-In Only)

James operates fully offline by default. Cloud services are used only when you explicitly configure them in backend/.env:

Service Env Variable What Is Sent When
llama.cpp (local) AI_MODE=local Nothing — runs on your machine Only if you run a local model server
Groq GROQ_API_KEY Chat messages, system prompt, tool schemas Each LLM request
OpenRouter OPENROUTER_API_KEY Chat messages, system prompt, tool schemas Each LLM request
Google Gemini GEMINI_API_KEY Chat messages, system prompt, tool schemas, image data (vision) Each LLM/vision request
Pollinations.ai (none — zero-auth) Image generation prompt Each image generation
DuckDuckGo (none) Search query Each web search
edge-tts (none — Microsoft) Text to be synthesized Each TTS request

API keys are never logged, never stored in the database, and never sent to any provider other than the one they belong to. The Gemini API key is sent via the x-goog-api-key header, not in URL query parameters.

3. Data We Never Collect

  • No analytics, telemetry, or usage tracking.
  • No account creation or user identification.
  • No advertising or marketing cookies.
  • No data sharing with third parties.
  • No cloud sync — everything stays on your device.

4. File Operations & Safety

James can perform guarded file operations on your local machine. All mutating operations follow a strict safety model:

  • Preview — reads file content after validating the file is within an approved index root and passes policy checks.
  • Open — opens a file with the OS default application only after explicit user confirmation. Executable and script file types are never opened.
  • Edit — creates a diff proposal that must be explicitly confirmed before any file is modified. A backup is created before every edit. Edits can be undone from the backup.
  • Indexing — scans user-approved folders. Protected directories (system paths, credential folders, hidden directories) are never indexed. Sensitive files (.env, keys, tokens) are never read or indexed.

5. Network & Access

  • The backend binds to 127.0.0.1:8000 (loopback only) by default. It is not exposed to the network.
  • CORS allows only localhost:5173 and localhost:8081 (local dev frontend).
  • WebSocket connections require an allowed origin header.
  • SSRF protections block requests to private IPs, loopback addresses, and cloud metadata endpoints.

6. Voice & Transcription

Voice transcription uses whisper.cpp running locally via subprocess. Audio is converted to 16 kHz mono WAV using ffmpeg and processed entirely on your machine. No audio is sent to any server.

7. P2P & Device Pairing

Device pairing uses a short-lived, single-use PIN (5-minute expiry). Paired devices are stored in a local trust store. The P2P proxy only routes to addresses stored at pairing time — it never constructs URLs from user-supplied device IDs.

8. Your Controls

  • Disable chat history — set CHAT_HISTORY_ENABLED=false in backend/.env.
  • Disable auto-indexing — set AUTO_INDEX_ENABLED=false.
  • Stay offline — set AI_MODE=offline (the default). No cloud provider is contacted.
  • Delete your data — delete data/rag_index.db, history/, backups/, and output_files/.
  • Revoke device trust — use POST /api/devices/revoke/{device_id}.

9. Limitations

James is a local tool, not a hosted service. We cannot:

  • Access your data — it never leaves your machine (except the opt-in cloud calls above).
  • Recover lost backups or history — they are local files.
  • Guarantee availability — James runs on your hardware.

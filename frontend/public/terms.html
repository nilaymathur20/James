2. Description of Service

James is a privacy-first, local-first personal AI assistant that runs on your local machine. It provides:

  • Local file indexing and full-text search (SQLite FTS5)
  • Guarded file operations with proposals, backups, and undo
  • Optional AI chat via local models (llama.cpp) or cloud providers (Groq, OpenRouter, Gemini)
  • Local voice transcription (whisper.cpp) and text-to-speech (edge-tts)
  • Web search and page fetching with SSRF protections
  • Image generation via Pollinations.ai (zero-auth)
  • Optional P2P device pairing with PIN-based authentication
